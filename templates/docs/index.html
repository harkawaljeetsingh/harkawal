Harkawal Framework Documentation

A blazing-fast, zero-dependency Static Site Generator designed for building beautiful, component-based Bootstrap websites.

Getting Started

We built this tool completely from scratch in Node.js because we wanted to solve a simple problem: How do we achieve a modern, component-based architecture while maintaining the pure speed and simplicity of raw HTML?

Installation

Learn how to install the framework globally via NPM and scaffold your first project.

Theming

Discover how to use structural themes to instantly change the entire layout of your site.

Code Example

Writing components is incredibly easy. Just use our custom include tag:

<!-- Include a reusable navbar -->
<include src="navbar.html"></include>

<main class="container">
    <h1>Hello World!</h1>
</main>
